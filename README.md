# Сайти (Netlify)

- `bot` — посадкова бота «AI-агенти для контенту».
- `praktykum` — посадкова живого практикуму з монтажу.
- `ani` — посадкова інтенсиву Ані (комерційна нерухомість), кнопки ведуть у @Realtor_education_bot?start=int і ?start=test. Липка кнопка зверху, щоб не закривав значок Netlify.

Кожен сайт у Netlify підключений до цього репозиторію з **Base directory** `bot` або `praktykum`
(збірки немає, публікується сама папка, див. netlify.toml). Пуш у main оновлює сайт сам.
Джерело сторінок: index.html у кожній папці (повний HTML для Netlify).
